# puterminator

A chat agent for one person's put.io library, live at puterminator.com. It finds and plays files, makes download links, translates subtitles, and scores a library for junk, duplicates, release names and wrapper folders.

Cleanup is always a reviewable diff of renames, moves and trash. Nothing changes until the person applies it, and every run can be stopped, retried and undone.

It's a public, single-package app on Cloudflare Workers. It stays small, private by default, and cheap to run.
